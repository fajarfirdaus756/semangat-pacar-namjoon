SEMANGAT PACAR NAMJOON 💜

Isi folder:
- index.html
- style.css
- script.js

GAMBAR NAILONG:
1. Buka situs resmi Nailoong: https://www.nailoong.com/en-us/ipStar/Nailong/
2. Pilih gambar yang ingin digunakan sesuai hak penggunaan yang berlaku.
3. Simpan sebagai nailong.png
4. Taruh nailong.png di folder yang sama dengan index.html.

MENJALANKAN:
- Buka folder di VS Code.
- Jalankan index.html dengan browser atau Live Server.

MEMBAGIKAN:
Setelah selesai, folder ini bisa di-deploy ke layanan hosting statis seperti GitHub Pages atau Netlify sehingga menjadi link yang bisa dibagikan.
